# OncoTracer 5.0.0

Version 5 adds caller selection to ONT methylation. **Rockfish is the default**; `--methylation-caller modkit` retains the Dorado MM/ML workflow from 4.1. Illumina processing, ichorCNA fallback, Broad profiles, coarse rescues, recovery thresholds and variant resume behavior are retained.

## Prepare methylation resources

Rockfish needs raw R10.4.1 POD5 signal sampled at 5 kHz. FASTQ alone and MM/ML tags alone cannot replace the signal. It reports binary CpG 5mC; it does not separately measure 5hmC. This caller choice does not establish better diagnostic accuracy or make the classifier outputs interchangeable with Dorado 5mC+5hmC.

Install a private runtime and verify the pinned official source/checkpoint:

```bash
oncotracer prepare-rockfish --directory /path/to/resources/rockfish --python /path/to/python3.11
oncotracer prepare-rockfish --directory /path/to/resources/rockfish --verify-only
```

Use `--cuda` during preparation for CUDA 12.4 wheels, then `--gpu` at analysis time when GPU use is intended. CPU remains supported. Downloads happen during preparation; analysis never silently downloads or switches callers. Conda and Poetry installations invoke the same isolated runtime. `environments/native-rockfish.yml` records the optional Conda environment. The Docker image provisions a CUDA-capable Rockfish runtime separately from its existing CNA/variant environments; CPU execution remains supported. MARLIN resources and user-licensed Sturgeon remain explicit external inputs.

Merge the generated `rockfish/resources.yml` keys into the ONT project YAML along with the hg38 reference, Dorado base model, samtools and licensed classifier resources. `--resources` accepts that YAML during setup. A single-classifier project specifies `methylation_classifier: marlin` or `sturgeon`. A mixed cohort uses `methylation_classifier: tissue` and `methylation_sample_metadata: /path/to/samples.tsv`:

```text
sample	tissue	pod5
Blood_01	bone marrow	/raw/Blood_01/pod5_pass
CNS_01	CNS	/raw/CNS_01/pod5_pass
```

Each row must match one selected FASTQ library. The optional `moves_bam` contains matching primary alignments with `mv` and `ts` tags. Without it, Dorado generates move-tagged alignments from the selected POD5 reads. The configured Dorado base model must match the sequencing chemistry. Rockfish does not require a Dorado modified-base model. Only explicitly selected pass signal folders are processed.

## Launch ONT, FFPE and fresh Illumina

Use saved, checked project YAMLs. For the ONT command below, set `gpu_usage: false` and `methylation_gpu_usage: true` in its YAML; both Illumina commands explicitly use CPU. Set `analysis_memory` and `variant_memory` in each YAML to its memory budget, and select FFPE or fresh during Illumina setup. These concurrent example budgets assume a 128-thread host with approximately 1 TiB RAM: 126 total threads and 936 GiB, reserving the remainder for the operating system and monitoring. Scale them to the resources available on your host.

```bash
# ONT: 66 total threads; example memory budget 360 GB.
oncotracer run --config /path/to/ONT/config/run.yml --backend docker --image carlosfarkas/oncotracer:5.0.0 --methylation --methylation-caller rockfish --threads 66 --parallel-samples 4 --no-merge-vcfs --resource-mode dynamic --storage-mode compact --cna-profile sensitive

# FFPE: 42 total threads; example memory budget 400 GB.
oncotracer run --config /path/to/FFPE/config/run.yml --backend conda --threads 42 --parallel-samples 7 --no-merge-vcfs --cpu --resource-mode fixed --storage-mode compact --cna-profile standard

# Fresh Illumina: 18 total threads; example memory budget 176 GB.
oncotracer run --config /path/to/Fresh/config/run.yml --backend conda --threads 18 --parallel-samples 3 --no-merge-vcfs --cpu --resource-mode fixed --storage-mode compact --cna-profile standard
```

For Docker, keep external classifier resources at their configured paths. Use a Dorado build compatible with the image’s Linux libraries and test `dorado --version` inside the image; a system MinKNOW bundle can require newer glibc. For native Conda, use `--backend conda` with the prepared Rockfish resource paths. For Poetry, use `poetry run oncotracer` and `--backend poetry`. Resource limits constrain the complete job; they are not per-sample allocations. Run `oncotracer check --config /path/to/project/config/run.yml` before launch.

To accelerate only ONT methylation, set `gpu_usage: false` and `methylation_gpu_usage: true` in the ONT YAML, then omit both `--cpu` and `--gpu` from its run command. Dorado, Rockfish and MARLIN use the existing bounded GPU queue; variants retain CPU execution. An explicit `--cpu` overrides both settings. Record GPU timing separately when comparing CPU-only and accelerated runs.

## Explicit Modkit compatibility

For an existing MM/ML BAM, set `methylation_caller: modkit` in the saved YAML or pass it explicitly. Tissue metadata then uses the `modbam` column from 4.1. Single-classifier example:

```bash
oncotracer run --config /path/to/ONT-modkit/config/run.yml --backend conda --methylation --methylation-caller modkit --marlin --modbam /path/to/completed.bam --cpu
```

For Dorado modified-base calling from POD5, retain both matching Dorado base and modified-base models and explicitly select Modkit. Missing Rockfish signal/resources cause an actionable error, never an automatic Modkit fallback.

## Provenance and validation scope

The caller, pinned source/model hashes, input signal inventory, move-tagged alignments, confidence threshold, measured CpGs and classifier inputs are recorded. Switching callers changes checkpoint signatures. Both-strand calls are mapped to reference CpG coordinates before aggregation. Rockfish applies MAPQ/base quality ≥20 and read-call confidence ≥0.8; missing CpGs remain missing. Sturgeon and MARLIN keep their existing probe aggregation/classification steps.

The Figure 4 pilot is a technical adapter check, not independent validation of diagnostic accuracy. Software tests and sample-level benchmark completion are reported separately. The November 16 version 4.1 benchmarks were stopped and their study outputs removed before preparing fresh version 5 runs. Original inputs and public reference/model caches are retained; previous sample alignments, variant calls and imputation results are not reused. The [completed 58-sample benchmark](../benchmarks/2026-11-23.md) now reports all three validated runs, stage timings, resource usage and the retained ONT QC exclusions.

### Task scheduling correction

The release candidate now assigns separate budgets to serial germline calling, Mutect2, GLIMPSE2 phasing/ligation and annotation. Independent tasks can overlap without reserving the entire sample budget for one mostly serial command. The tool-side Java heap is bounded by the matching Nextflow task memory reservation, and traces expose both requested and observed resources. This correction preserves the 4.1 CNA fallback and rescue paths and the v5 Rockfish/Modkit choice. The completed study reports measured fresh-run timings. It does not establish a speedup over an unfinished v4.1 run.
