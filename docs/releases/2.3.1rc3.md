# OncoTracer 2.3.1rc3 candidate

Cohort VCF merging is optional for the Illumina Fresh and FFPE workflows.
The default remains enabled. Every sample still receives its annotated VCF
and reports when the cohort merge is disabled.

```bash
oncotracer run --config project/config/run.yml --no-merge-vcfs
oncotracer variants --config variants.yml --no-merge-vcfs
oncotracer setup --terminal --variants --no-merge-vcfs
oncotracer --interactive --no-merge-vcfs
nextflow run main.nf --analysis full --config project/config/run.yml --merge_vcfs false
```

Use `--merge-vcfs` to enable the merge explicitly. For a saved choice, set
`variant_merge_vcfs: false` in YAML. A command-line choice overrides YAML for
that invocation without rewriting it. Terminal setup asks whether to merge;
both browser forms have a **Merge sample VCFs into cohort VCFs** checkbox.
Nextflow accepts `--merge_vcfs true`, `--merge_vcfs false`, or
`--no_merge_vcfs`; these also work with the interactive launcher.

Disabled merging is recorded as `cohort_status: skipped`. Sample failures
remain failures. Existing cohort files are preserved but are not linked as
outputs of a skipped merge. Re-enabling merging uses the same per-sample
workflow parameters and normal validated continuation.

The Python/Conda application, standalone executable, Docker application and
Nextflow gateway share version `2.3.1rc3` (Docker tag `2.3.1-rc.3`). Scientific
environment definitions are unchanged. This is a candidate for local testing;
stable publication still requires the repository's complete release gates.
