# OncoTracer 2.3.1rc2

This maintenance preview fixes cohort merges that rejected equivalent ClinVar
annotations because per-sample bcftools command timestamps changed raw file
hashes. It verifies the retained source files against their original hashes and
compares complete annotation content under a documented, versioned policy.
Changed annotation records or releases still fail. Completed sample outputs are
retained and reused only after runtime, provenance and checksum validation.

The cohort schema is now `glimpse-cohort-v2`: caller-dependent `ANN_*` values are retained per sample in FORMAT, preventing a second false conflict between caller gene symbols and ClinVar gene/ID fallbacks. Shared ClinVar annotation conflicts remain fatal.

The release also reports cohort failure explicitly and preserves identical
bundled workflow paths across application updates to avoid unnecessary cache
invalidation. It includes the 2.3.1rc1 removal of integrated haplotype assessment
and retention of interrupted caller scratch. Partial scratch is preserved for
inspection; it is not automatically treated as a completed caller result.

The native executable, wheel, source tag and Docker image identify the same
source commit. Native and Docker workflows use the existing verified scientific
environments, including Nextflow 26.04.2. No scientific dependency definitions
change in this maintenance release. The root Nextflow entry delegates to the
same application. See [cohort provenance and continuation](../GLIMPSE_COHORT.md).

This is a prerelease, not a declaration that the separate stable-release
scientific parity and complete production-output acceptance gates have passed.
