# OncoTracer 6.3.0

ONT browser setup now runs MARLIN and Sturgeon in the same project. Previously,
combined CNA/methylation setup selected one classifier for the entire cohort.

Choose **CNA and methylation**, then drag each sample into **MARLIN**, **Sturgeon**
or **Skip methylation**. Dropdowns provide the same controls. Both assigned groups
run, and skipped samples retain CNA and enabled variant analysis. Methylation-only
projects and continuation from an existing ONT project also support both groups.

Before Run, the review explicitly shows whether CNA, variants and methylation
are enabled, and lists each sample's classifier. Those saved assignments remain
visible during execution. Assignments are recorded in
`config/methylation_assignments.tsv`; editing that file after review requires a
new check before launch.

## Start or update

```bash
python -m pip install --upgrade "https://github.com/cfarkas/oncotracer/releases/download/v6.3.0/oncotracer-6.3.0-py3-none-any.whl"
oncotracer interactive --backend docker
```

Use the dependency card to install and verify the 6.3.0 Docker image. Finish or
stop existing jobs before changing their runtime. Existing projects retain their
saved analysis options; upgrading does not silently enable methylation.

## Inputs and preparation

You provide FASTQs, sample identities and roles, specimen information, the
classifier assignments, a project folder and compatible methylation input.
Rockfish remains the default and needs matching raw POD5. Modkit can reuse BAMs
with MM/ML calls. FASTQs alone cannot recover methylation.

Docker supplies the supported caller runtimes and MARLIN. Setup prepares the
required models and reference assets; Sturgeon requires the user's license
acceptance. Samples without recorded methylation remain explicitly unavailable
instead of receiving a prediction. See [the first-run guide](../first_run.md).

## Validation and retained behavior

Tests cover both classifier groups in a single saved project, named-library
signal isolation, skipped samples, assignment changes after review, browser drag
and dropdown controls, model/license visibility and the saved run summary.
Release publication also requires native CI, both QuickStart parity workflows,
documentation checks and container verification against the release source.

The CNA and variant workflows, ichorCNA fallback, Broad profiles and coarse
rescues are retained. Historical v5 cohort benchmark results remain historical;
this release does not present them as a new 6.3 benchmark.
