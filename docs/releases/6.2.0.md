# OncoTracer 6.2.0

Browser and terminal setup now check installed tools before configuration. If
analysis tools are missing, setup offers an installation plan and asks for
approval. Installation runs in the backend, with progress, logs, cancellation
and retry in the browser. The tools are checked again when it finishes.

```bash
oncotracer interactive --backend docker
# Terminal questions:
oncotracer setup --terminal --backend docker
```

The check inventories host executables, verifies configured native environments,
checks Docker access and inspects tools inside the selected image. It compares
an official versioned image with the latest stable release and its published
image digest. Custom and digest-pinned images are retained unless the user
chooses a replacement. Offline checks still inspect installed tools and report
that online update status is unavailable.

Opening setup, checking tools or reviewing a plan does not install anything.
Conda installations use a new managed folder. Installation and analysis cannot
run simultaneously in the same setup session. Docker Engine or Conda must
already be available; setup does not change host drivers or daemon permissions.
Models, reference data and licensed assets remain subject to their workflow
checks and license acknowledgements.

This release also includes the v6.0.1 `interactive` alias, helpful command errors
and the fix for the Detect tools resource-field error. Upgrade the Python
launcher and restart old browser sessions to use these changes; pulling a newer
Docker image alone does not update a running launcher.

## Install or upgrade

```bash
python -m pip install --upgrade "https://github.com/cfarkas/oncotracer/releases/download/v6.2.0/oncotracer-6.2.0-py3-none-any.whl"
oncotracer --version
oncotracer interactive --backend docker
```

## Validation

Release publication requires the native test suite, real Firefox setup tests,
Docker checks and both QuickStart parity workflows to pass for the same source
commit. New tests cover read-only inspection, explicit approval, immutable image
selection, offline updates, failed installations, retries, cancellation,
terminal installation and exclusion of installation during analysis.

The scientific workflow, ichorCNA fallback, Broad profiles and coarse recovery
remain unchanged. The [study benchmark](../benchmarks/2026-11-23.md) records v5;
this release does not relabel it as a v6.2 cohort benchmark. Existing release
notes, images and artifacts remain available.
