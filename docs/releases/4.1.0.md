# OncoTracer 4.1.0

Mixed ONT cohorts can assign methylation classifiers from explicit tissue metadata. MARLIN is used for peripheral blood, PBMC or marrow; Sturgeon for CNS. Unknown or other tissues remain unassigned. Original modified-base BAMs are processed with the corrected reference-CpG aggregation, with per-sample native score vectors and provenance retained. Docker and Podman can bind explicitly configured, separately installed classifier environments and models read-only. These licensed resources are not distributed in the image.

Set `methylation: true`, `methylation_classifier: tissue` and `methylation_sample_metadata: /absolute/path/samples.tsv`. The TSV requires exactly one `sample`, `tissue`, `modbam` row for every selected ONT sample; relative BAM paths are resolved against the TSV. The existing MARLIN/Sturgeon tool, model, checksum and license-acknowledgement settings remain required. Routing uses recorded tissue, not a predicted diagnosis. Existing explicit single-model workflows remain available.

Illumina `--one-cpu-per-sample` (YAML `variant_one_cpu_per_sample: true`) starts every selected sample with one CPU. Supply at least as many total threads as samples and sufficient memory. Each analysis reserves 8 GiB; local report models borrow another 24 GiB through a shared, process-owned memory pool. Interrupted or killed workers release their slots automatically. Cohort VCF merging remains optional through `--merge-vcfs` or `--no-merge-vcfs`; per-sample VCFs remain available with either choice.

Multi-sample runs produce `09_cohort_figure/04_cohort_figure.pdf`, SVG and PNG, numbered source tables, a separate figure legend and a checksum manifest. The figure contains every selected sample, genome-wide CNA, measured autosomal depth, accepted event counts, evidence labels and available tissue-eligible methylation classes/scores. A single sample does not produce a cohort figure. Set `cohort_figure: false` to disable it.

Evidence-gated ichorCNA fallback remains available for primary QDNAseq QC failures. Coarse supported relative events, exploratory chromosome/arm gain/loss assignments and unassessable samples remain distinct. Exploratory candidates are exported with explicit regions rather than a generic broad label; they do not establish tumour fraction or absolute ploidy. No QC thresholds are relaxed in this release.

Public scientific regression uses the pinned native 3.0.0 Figure 1 pipeline, with exact event comparisons and explicit expected QC limitations. Historical v1.1 results are retained as a different-method comparison; full v1.1 numerical parity is not claimed.

The release retains the 4.0 Clair3 worker recovery and FFPE dashboard fixes. CI actions use pinned Node 24 versions; stopped CI runs release generated Fontconfig directory guards so subsequent checkouts can clean their workspace.

[GitHub release](https://github.com/cfarkas/oncotracer/releases/tag/v4.1.0). Docker: `carlosfarkas/oncotracer:4.1.0`. Software release and completion of any full study benchmark are separate validation events.
