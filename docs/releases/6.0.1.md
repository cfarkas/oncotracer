# OncoTracer 6.0.1

Typing `oncotracer interactive` now opens browser setup. It is equivalent to
`oncotracer --interactive`; both accept `--backend docker` and the existing
setup options.

Misspelled commands suggest the closest valid command and show examples.
Misspelled options suggest a matching option for that command, and argument
errors point to its help page. Suggestions never execute an analysis.
`oncotracer help` and `oncotracer help run` also work.

```bash
oncotracer interactive --backend docker
oncotracer help run
```

Upgrade an existing Python installation:

```bash
python -m pip install --upgrade "https://github.com/cfarkas/oncotracer/releases/download/v6.0.1/oncotracer-6.0.1-py3-none-any.whl"
docker pull carlosfarkas/oncotracer:6.0.1
```

The browser's **Detect tools** request now accepts the imputation settings sent
by the form. A failed check shows the returned error beside the button and
preserves entered paths. Tool discovery remains read-only.

The scientific workflows and resource definitions are unchanged from
[6.0.0](6.0.0.md). Existing releases and versioned images are retained.
The [58-sample benchmark](../benchmarks/2026-11-23.md) remains historical v5
measurements. Current CI and container validation have separate provenance.
