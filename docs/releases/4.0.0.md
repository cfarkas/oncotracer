# OncoTracer 4.0.0

This release corrects an ONT worker-scheduling defect that could leave Clair3 jobs alive without progress and permit unexpected worker termination. GNU Parallel now receives a constant numeric concurrency ceiling. A bounded admission controller uses PID-and-start-time leases to adapt resources safely, reclaim dead workers and preserve running work when limits shrink. It never signals recorded lease PIDs or rewrites GNU Parallel jobs files.

Fatal sample-worker failures cancel remaining cohort workers and leave queued work unstarted. Completed scientific outputs and diagnostic records remain available. Scientific QC exclusions remain distinct from execution failures.

The release retains corrected native reference-CpG aggregation for MARLIN and Sturgeon, evidence-gated ichorCNA fallback, compact storage, and the FFPE dashboard inventory fix. Scientific thresholds and caller arguments are unchanged by this scheduler correction. Existing 2.3 and 3.0 managed environments and project checkpoints are accepted only after their usual integrity checks.

Regression tests exercise dynamic concurrency growth and shrinkage, stale PID reuse without signalling live processes, bounded retries after SIGKILL, and cancellation of sibling workers after a sample failure. The Docker build includes the same scheduler recovery tests as the local suite.

The interrupted 3.0.0 study run is excluded from performance claims. The 26-FFPE, 22-ONT and 11-fresh-Illumina benchmark is restarted from original FASTQs with empty output directories. Its final measurements will be published only after all cohort outputs pass validation; release of this software does not imply completion of that benchmark.

[GitHub release](https://github.com/cfarkas/oncotracer/releases/tag/v4.0.0). Docker: `carlosfarkas/oncotracer:4.0.0`.
