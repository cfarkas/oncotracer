OncoTracer v2.0.0

A native LP-WGS copy-number analysis application that converts Illumina or Oxford Nanopore FASTQs into CNA tables, cytogenomic notation, plots, reports, and reproducible run records.

v2 is the active documentation. Normal v2 execution does not install or invoke Nextflow. The frozen v1.1 Nextflow workflow is retained only as an independent release-parity comparator.
Native analysis path
Illumina FASTQ → BWA/Picard → qDNAseq
ONT FASTQ      → minimap2   → HMMcopy/ichorCNA
                              ↓
BAM refinement → CNA tables → plots/reports

Installation

On Linux, install the copied single-file executable globally and prepare exactly one scientific backend.

Stable release asset

gh release download v2.0.0 --repo cfarkas/oncotracer --dir oncotracer-v2.0.0
cd oncotracer-v2.0.0
sha256sum -c SHA256SUMS
sudo install -m 0755 oncotracer /usr/local/bin/oncotracer
oncotracer --version
oncotracer provenance --json

Build the same executable from the current source tree

git clone https://github.com/cfarkas/oncotracer.git
cd oncotracer
SOURCE_COMMIT="$(git rev-parse HEAD)"
SOURCE_SHA256="$(git -c tar.umask=0002 archive --format=tar "$SOURCE_COMMIT" | sha256sum | awk '{print $1}')"
python3 scripts/build_native_binary.py --output dist/oncotracer \
  --source-commit "$SOURCE_COMMIT" --source-sha256 "$SOURCE_SHA256"
sudo install -m 0755 dist/oncotracer /usr/local/bin/oncotracer
oncotracer --version

Prepare one backend

Conda
oncotracer install --conda
oncotracer doctor --backend conda

Creates isolated core, qDNAseq, ichorCNA, classifier, and GISTIC2 environments.

Docker
oncotracer install --docker
oncotracer doctor --backend docker

Validates Docker and pulls the immutable native v2 image.

Singularity / Apptainer
oncotracer install --singularity
oncotracer doctor --backend singularity
Poetry development route
./oncotracer install --poetry
poetry run oncotracer --version

Run an analysis

Automatic Setup discovers FASTQs, validates sample identities and layouts, and writes a native YAML configuration. The generated YAML is then passed to the native runner.

Illumina

oncotracer auto --mode illumina \
  --reads-folder /path/to/project/reads \
  --sample-table /path/to/project/samples.csv
oncotracer run --backend conda \
  --config /path/to/project/config/illumina.auto.yml

Oxford Nanopore

oncotracer auto --mode ont \
  --reads-folder /path/to/project/fastq_pass \
  --sample-table /path/to/project/samples.csv
oncotracer run --backend conda \
  --config /path/to/project/config/ont.auto.yml

Every completed run writes .oncotracer-native/trace.tsv, a content-aware stage ledger, workflow summary, checksum manifest, CNA event tables, refined bins, and plots. Resume behavior is based on content-matched stage records rather than a Nextflow work directory.

QuickStart 1: Illumina and ONT

The first public example downloads one Illumina library and one ONT library, then executes both native analysis paths.

oncotracer quickstart 1 --backend conda --test-root "$PWD/quickstart1"

Expected public samples: Illumina ERR12341627 and ONT DRR165691.

QuickStart 2: three HCC1143 libraries

The second public example exercises the multi-library Illumina path using three HCC1143 datasets.

oncotracer quickstart 2 --backend conda --test-root "$PWD/quickstart2"

Release assurance and provenance

The stable v2 release is fail-closed behind native source and executable validation, five managed-environment solves, container validation, complete QuickStart 1 parity against frozen v1.1 for Illumina and ONT, and complete three-library HCC1143 QuickStart 2 parity.

Parity checks include exact sample sets, CNA-event reciprocal-overlap precision and recall, refined-bin coverage, profile correlation, absolute log2 differences, output hashes, and proof that the native trace contains no Nextflow command. Release assets include SHA256SUMS, the copied executable, a parity audit archive, and release-provenance.json.

Legacy v1.1

Nextflow documentation is legacy material for reproducing v1.1 or understanding the independent parity comparator. It is not the normal OncoTracer v2 execution route.

OncoTracer is for research use. CNA calls require expert review, laboratory validation, and interpretation together with pathology and orthogonal molecular evidence.
